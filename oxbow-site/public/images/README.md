## 📌 Tips

- Keep the same filename. The code maps names automatically.
- Compress images before uploading — aim for < 300 KB per image using Squoosh or TinyJPG.
- For the logo, use a transparent PNG with a white/light-coloured icon.
- Images are served from `/public/images/` — they go live immediately on deploy.
